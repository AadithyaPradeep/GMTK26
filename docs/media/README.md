## Capture tips

1. Open `GMTK26 V1` in Unity 6000.5.4f1 and enter Play mode (or use a packaged build).
2. Prefer 1920x1080 Game view captures, or the itch splash for `homepage.png`.
3. Suggested variety: farm chaos, grab/hold, bomb countdown, wave UI, Chaos or boss moment.
4. Keep filenames exactly as listed (lowercase, hyphens).

Until these files exist, GitHub will show broken image links in the README.
